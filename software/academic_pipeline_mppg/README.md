# Academic Pipeline MPPG

Pacote Python do Academic Pipeline do projeto MPPG.

A distribuição expõe o comando `academic-pipeline` e o módulo
`python -m academic_pipeline`. Os recursos institucionais, modelos,
prompts e templates necessários à execução são incluídos por um
allowlist explícito no `pyproject.toml`.

Este README descreve a distribuição técnica. A documentação operacional
e os registros de refatoração permanecem no repositório principal.
