# CSL para DOCX

Coloque aqui arquivos CSL caso queira DOCX com citação/referência rigorosa via Pandoc.

Exemplos de nomes esperados nos TOMLs:

- `apa.csl`
- `associacao-brasileira-de-normas-tecnicas.csl`

O `.bib` continua neutro. O CSL é usado apenas na renderização DOCX via Pandoc quando `[docx].usar_pandoc = true`.
